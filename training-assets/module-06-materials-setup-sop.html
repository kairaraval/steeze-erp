Materials, Inventory & Tagging — Setup SOP

A one-time clean-up project that becomes a permanent standard: get every fabric and trim fully recorded, physically swatched, correctly counted, clearly tagged, and right-sized — so the company can monitor stock and compare prices with confidence.

RolePurchasing Admin TypeSetup project → ongoing SOP Works withCutting · Sales · Accounting Read time~18 min

00 — Why this matters

From "we think we have it" to "we know we have it"

Right now material information lives in people's heads and in scattered records. You cannot compare prices you haven't written down, and you cannot trust stock you haven't counted. This project fixes that in five workstreams. Do them roughly in order — each one makes the next easier.

The goal

Every fabric and trim: fully specced in the Materials Library, swatched physically, counted against the OS, tagged on the shelf, and reviewed for over-stock. Once set up, keeping it true is a light weekly habit.

Workstream 1

Complete the Materials Library

The Materials Library already lists every fabric and trim we stock (pulled live from inventory). Most cards are missing their specs. Your job is to make every card complete and accurate.

  1. Open each material and click "Add specs"

    Materials Library

    Work through Fabrics first, then Trims. The "needs specs" tag shows which ones aren't done yet.

  2. Fill every field

    Name (correct, consistent), material type, composition, GSM, width, yield (yd/kg), typical use, supplier, unit, current price, MOQ and lead time.

  3. Upload colour swatch photos

    One clear photo per colour, each labelled with the colour name. Shoot in good light on a plain background so the colour is true.

  4. Confirm the price

    Check the unit price against the latest supplier quote. This is what makes price comparison possible later — an out-of-date price is worse than none.

Done means

No fabric card left with the "needs specs" tag, every fabric has a GSM and at least one colour swatch, and every price is one you confirmed this month.

Workstream 2

Build the physical swatch library

The digital library is for reference and quoting; a physical swatch book is for touch, true colour, and showing clients. Build one master set and a copy for Sales.

  • Cut a consistent swatch of every fabric (and key trims) — same size for all, so the book is tidy and comparable.
  • Label each swatch with the exact same name used in the Materials Library, plus GSM and composition. The physical and digital names must match — that link is the whole point.
  • Organise by type (e.g. all interlocks together) so a fabric is easy to find.
  • Make a Sales copy. Give Sales their own swatch set so they can show clients without borrowing the master.
  • Keep it current. When a new fabric is added or one is dropped, update both books the same week.
Watch out

If a physical swatch is named differently from its library card, the two drift apart and people stop trusting either. One name, everywhere.

Workstream 3

Actual inventory vs the OS

Count what is physically on the shelf and reconcile it with what the OS says. This is the truth-check that everything else depends on.

  1. Physically count each fabric

    Go fabric by fabric. Record the real quantity on hand.

  2. Compare to the OS figure

    Note every gap — where the shelf and the system disagree, and by how much.

  3. Correct the OS

    Adjust the system to match reality (via a stock movement / adjustment), with a short note on why. From this point the OS is trusted.

  4. Tag every fabric

    one tag per fabric, not per roll

    Print a shelf tag for each fabric so anyone can identify it at a glance (see "How to print tags" below). Place one tag per fabric location — no need to tag every roll.

Cadence after setup

Once reconciled, do a rolling cycle count — a slice of the inventory each week — so the OS never drifts far from the shelf again.

Workstream 4

Tags for incoming materials

When new material arrives, it should be tagged immediately so the cutting team can identify it without ever having to ask Purchasing "what is this fabric for?"

  • Tag at receiving. As part of the receive step, print and attach a tag to the incoming material.
  • The tag identifies the fabric — name, GSM, composition, width, colour, and supplier — so cutting reads the tag, not a guess.
  • Make it a habit. No material is put away untagged. A roll with no tag is a question waiting to happen.
Why cutting cares

A clear tag means the cutting team pulls the right fabric the first time — fewer wrong cuts, fewer interruptions to Purchasing, faster production.

Workstream 5

Check remaining fabrics & returns

Part of the count is deciding what to do with what's left — especially fabric we over-ordered.

  • Flag slow/idle fabric. Material that isn't tied to an upcoming job and hasn't moved in a long time is tying up cash.
  • Check return eligibility. For over-ordered fabric, find out whether the supplier will take some back — within what window, in what condition, and at what (if any) restocking cost.
  • Decide per item: return it, use it on an upcoming job, or keep as stock if it's a staple. Record the decision.
  • Coordinate with Accounting on any return so credits and payments are adjusted correctly.
Approval

Returns and any restocking costs are a money decision — surface the plan and get the CEO's approval before acting with the supplier.

Tool

How to print tags

Tags are generated straight from the Materials Library, so they always carry the correct, current information.

  1. Open the Materials Library

    Pick the Fabrics or Trims tab. Use the filters (type, supplier) or search to narrow to what you want to tag.

  2. Click "🏷 Print tags"

    A print sheet opens with one tag per material currently shown — name, GSM, composition, width, colour, supplier, and a short code.

  3. Print & attach

    Print, cut, and attach. One tag per fabric on the shelf (Workstream 3); a tag on each incoming material at receiving (Workstream 4).

Tip

Because tags pull live from the library, finish a material's specs first (Workstream 1) so its tag is complete. Re-print a tag any time its details change.

SOP

Master checklist

Work top to bottom. This is the standard the role is held to — not a one-time to-do.

1 · Materials Library complete

  • Every fabric card has: name, type, composition, GSM, width, yield, unit, price, MOQ, lead time
  • Every fabric has at least one labelled colour swatch photo
  • Every trim card completed with spec/size, colour, supplier, price, MOQ
  • All prices confirmed against latest supplier quote this month
  • No material left with the "needs specs" tag

2 · Physical swatch library

  • A physical swatch cut for every fabric (and key trims)
  • Each swatch labelled with the same name + GSM + composition as the library
  • Master swatch book organised by type
  • Sales given their own copy of the swatch set

3 · Inventory vs OS

  • Every fabric physically counted
  • Gaps between shelf and OS recorded
  • OS corrected to match reality, with notes
  • One printed tag placed per fabric (not per roll)
  • Weekly cycle-count routine started

4 · Incoming-material tags

  • Tag printed and attached to every incoming material at receiving
  • Tag shows name, GSM, composition, width, colour, supplier
  • No material stored untagged

5 · Remaining fabrics & returns

  • Idle / over-ordered fabric flagged
  • Supplier return eligibility checked for over-stock
  • Decision recorded per item (return / use / keep)
  • Returns coordinated with Accounting and approved by the CEO

Reference

Data standards

Small rules that keep the library trustworthy as it grows:

  • One name per material — identical in the OS, the library, and the physical swatch. Never two spellings of the same fabric.
  • GSM is mandatory for fabric — it's the single most useful spec for identifying and comparing.
  • Swatch photos: true colour — plain background, good light, one per colour, labelled.
  • Prices carry a date — always know how fresh a price is.
  • Tag everything — on the shelf and on arrival. An untagged material is an unanswered question.

Check yourself

Knowledge check

Six questions. 80% to pass.

Q1How many tags go on each fabric during the inventory setup?

Workstream 3: one tag per fabric so it's identifiable on the shelf — no need to tag every roll.

Q2Why must the physical swatch use the same name as the library card?

Different names make the two drift apart and people stop trusting either. One name, everywhere.

Q3After counting, the shelf and OS disagree. What do you do?

The physical count is the truth; adjust the system to match it so the OS becomes trusted.

Q4What is the point of tagging incoming materials?

A clear tag lets cutting pull the right fabric the first time, with no interruption to Purchasing.

Q5You find fabric that was clearly over-ordered. First move?

Over-stock may be returnable; returns are a money decision, so plan it and get approval.

Q6Where do printed tags get their information?

Tags generate from the library — finish a material's specs first so its tag is complete.
